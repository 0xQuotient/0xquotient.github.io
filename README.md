# Derrick J. Last Jr

Personal site: projects, writing, my lab, and how I work.

**Live:** https://0xquotient.github.io

Written with Claude AI. Design direction and content are mine.

## About the build

A single static `index.html` with the CSS and JavaScript inline. No build step, no dependencies, no tracking. Hosted on GitHub Pages. Fonts (Chakra Petch, Geist, Geist Mono) load from Google Fonts.

## Files
